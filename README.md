# Tidewick – learn options through a mystery story

**Tidewick** is a Grok Bot template: a mystery you solve in chat, where every chapter teaches one real options idea, from complete beginner upwards. Paper money only: fictional pounds, no live prices, and never financial advice.

**Status:** skeleton, v0.1.0, not published. The story is in progress: chapter scenes are placeholders (`[KEEPER]`, `[COMPANION]`, ...) while it is being written. The numbers in each chapter are already real and checked.

## Repo layout
| Folder / file | What |
|---|---|
| `bot.json` | Profile (name, tagline), memories, getting-started skill. `skills[]` is the single source for which skills exist. No connections |
| `routines.json` | One routine, `tidewick-next-chapter`, `"enabled": false` (off until the player says yes) |
| `skills/` | `tidewick-getting-started`, `tidewick-core-rules`, `tidewick-chapter-player`, `tidewick-recap-quiz` |
| `fixed-files/` | What an installed bot fetches at a pinned tag into `~/.tidewick/`: `engine/` (case maths + casebook scripts), `chapters/` (format, 16-chapter curriculum, one file per chapter), `casebook/` (format + example). See `fixed-files/MANIFEST.md` |
| `tests/` | Unit tests for the maths, the casebook, the chapters and the curriculum |
| `build.py` | Packs bot.json, routines.json and the skills into `args/create_bot_share_json.args.json`, with hard checks (92,000-byte limit, routines off, slug prefix, private-data scan) |
| `banned_scan.py` · `banned.txt` | Banned-phrase and private-data scan |
| `docs/` · `listing/` · `proof/` | Filled at later release gates |
| `args/` | Generated by `build.py`; never hand-edited |

## Checks
From the repo root (Python 3; Pillow optional, for PNG charts):
```
python3 -m unittest discover -s tests -v
python3 fixed-files/engine/case_maths.py check fixed-files/chapters/ch01.md fixed-files/chapters/ch02.md
python3 banned_scan.py . --banned banned.txt --private-terms ../private-terms.txt
python3 build.py --private-terms ../private-terms.txt
```
The private-terms file lives **outside** this repo (see `private-terms.example.txt` for the format). It is never committed.
