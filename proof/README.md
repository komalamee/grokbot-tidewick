# proof

Concrete evidence for each release. No release without it (owner's rule, 29 Sep 2026). Fake data only; no real names, emails or places from anyone's own data.

The repo is **public**, so everything in here is published the moment it is pushed. Screenshots are the easiest way to leak by accident: check each one for an email address, a real Sheet or Drive link, a browser tab, an account name, a file path or another person's name before it goes in, and redact rather than crop.

| Folder | What goes in it |
|---|---|
| `screenshots/` | Message 1, the first result, the routines question, the data Sheet (matching the approved mock-up), the staged card |
| `test-runs/` | One file per routine test: date, agreed time, actual fire time, message sent or silence; clean-agent retest transcripts |

Name files `v<version>-<what>-<date>.png|md`, e.g. `v1.0.0-first-result-2026-09-29.png`. Link each one from `docs/RETEST.md`.
